## 1. 快速开始

### 1.1 安装与启动

**安装版**（推荐）：

1. 双击 `oimimo-setup.exe`
2. 如果 Windows 弹出 SmartScreen 提示（"Windows 已保护你的电脑"），点击 **"更多信息"** → **"仍要运行"**
3. 选择安装路径（默认 `%LOCALAPPDATA%\oimimo\`），点击安装
4. 安装完成后自动创建桌面快捷方式和开始菜单项
5. 双击桌面图标或从开始菜单启动

**便携版**：

1. 将 `oimimo-portable-win64.zip` 解压到任意文件夹（如 U 盘、移动硬盘）
2. 进入解压后的文件夹，双击 `oimimo.exe` 运行
3. 同样可能遇到 SmartScreen 提示，处理方式同上

**启动后**：程序会自动打开默认浏览器，访问 `http://127.0.0.1:1096`。你会看到软件的主页仪表盘。系统托盘（右下角）会出现 oimimo 的图标，右键可以退出程序。

### 1.2 首次使用流程

**三步上手**：

1. **创建客户**：点击侧边栏「客户」→「新建客户」→ 填入客户名称（如"小明"），保存
2. **创建订单**：点击侧边栏「排单列表」→「新建订单」→ 填写标题、选择客户、填入金额、设置截稿日期 → 保存
3. **排期**：在主页的甘特图上，拖拽订单条形图到合适的日期区间

之后你可以：在日历上查看排期 → 完成后推进阶段 → 记录收款 → 订单自动归档。

### 1.3 界面概览

左侧是**侧边栏导航**，包含以下入口（从上到下）：

| 页面 | 路径 | 用途 |
|---|---|---|
| 主页 | `/` | 仪表盘、甘特图、本周排单、逾期提醒 |
| 日历 | `/calendar` | 日历视图、拖拽排期 |
| 排单列表 | `/orders` | 订单表格、筛选、批量操作 |
| 看板 | `/orders/kanban` | 阶段看板、拖拽流转 |
| 收入 | `/income` | 收入图表、时薪统计 |
| 画廊 | `/gallery` | 作品展示、图片管理 |
| 客户 | `/customers` | 客户管理、消费统计 |
| 小工具 | `/tools` | 价目表、小票打印机、回复模板 |
| 设置 | `/settings` | 主题、备份、日历订阅等配置 |

页面切换采用局部刷新 + 平滑过渡动画，不会有整页白屏。编辑中离开页面会弹出"未保存"确认提示。

## 2. 主页仪表盘

主页是你接单排单的核心控制台，包含四个区域。

### 2.1 统计卡

顶部一行 5 张统计卡：

| 指标 | 含义 |
|---|---|
| **进行中** | 当前未完成且未归档的订单数量 |
| **本月收入** | 本月到账净额（扣除平台手续费后），含环比变化百分比 |
| **逾期** | 截稿日已过但仍未完成的订单数量 |
| **已完成** | 已归档的完成订单数量 |
| **待收金额** | 应收净额减去已到账，即还没收到的钱 |

**点击任意统计卡**会弹出小票明细窗口，显示具体的金额明细。待收小票按分期单逐笔列出（应收/已到/待收三列），到账小票按笔一行显示。

统计卡上方有**时间范围选择器**：本月 / 本季度 / 本年 / 全部 / 自定义日期区间。

### 2.2 甘特图排期

甘特图以时间轴方式展示所有订单的排期：

- **4 种粒度**：日 / 周 / 月 / 年，点击切换
- **拖拽改期**：鼠标拖拽订单条形图可改变开始/结束日期，松手自动保存
- **拖拽调时长**：拖拽条形图右边缘可调整截稿日期
- **今日定位**：当前日期有一条竖线标记，打开时自动居中
- **颜色含义**：条形图颜色跟随当前着色模式（默认按阶段着色）

### 2.3 本周排单表

展示本周内有排期安排的订单列表，包括：标题、客户、阶段、截稿日、剩余天数。

### 2.4 逾期提醒

展示截稿日已过但未完成的订单，按逾期天数排序。每行显示逾期天数红色徽标，提醒你优先处理。

## 3. 日历视图

日历提供月视图和周视图两种模式，支持拖拽排期和丰富的颜色编码。

### 3.1 视图切换

- 点击日历上方的 **"月"** / **"周"** 按钮切换视图
- 月视图看全月概览，周视图看单周细节
- 左右箭头翻页，"今天"按钮回到当前日期

### 3.2 未排期池拖拽入历

日历右侧有一个**未排期池**面板，列出所有已创建但还没安排排期的订单。将订单卡片**拖拽到日历的某一天**，即可为其设置排期开始日期。拖入后默认排期时长为 7 天（可在订单编辑中调整）。

### 3.3 事件拖拽

- **移动**：拖拽日历上的事件到另一天 → 自动更新排期开始日
- **调时长**：拖拽事件的下边缘 → 自动更新截稿日期
- 所有拖拽操作松手即自动保存，无需手动确认

### 3.4 着色模式

点击日历上方的着色切换按钮，可在 5 种维度之间切换颜色编码：

| 模式 | 含义 |
|---|---|
| 按来源 | 不同约稿渠道（米画师/小红书/微博等）不同颜色 |
| 按阶段 | 不同制作阶段（草稿/线稿/上色等）不同颜色 |
| 按 DDL | 截稿紧急度着色（逾期红/临期橙/充裕绿） |
| 按收款 | 收款状态着色（已结算/未收款/欠款等） |
| 按类别 | 不同稿件类别（头像/立绘/Q版等）不同颜色 |

每种模式的颜色可在「设置 → 着色模式」中自定义。着色模式的选择会被记住，刷新页面后不丢失。

### 3.5 日历订阅（iOS/Android 同步）

可将排期信息同步到手机日历：

1. 进入 **设置 → 日历订阅**
2. 开启「启用日历订阅」开关
3. 系统生成一个 ICS 订阅链接（含安全令牌）
4. 点击「复制链接」
5. 在 iPhone 日历 App 中：设置 → 日历 → 账户 → 添加已订阅日历 → 粘贴链接
6. 在 Android 中：使用 Google 日历或其他支持 ICS 订阅的应用添加

**注意事项**：
- 首次启用时 Windows 会弹出防火墙询问，点击"允许"（否则手机无法连接）
- 日历订阅在本地 1097 端口运行，手机和电脑须在同一 WiFi/局域网
- 如需重新生成链接（令牌泄露时），点击「旋转令牌」

## 4. 排单列表

排单列表以表格形式展示所有订单，支持丰富的筛选和批量操作。

### 4.1 筛选与搜索

顶部筛选栏提供 5 种筛选条件，可叠加使用：

| 筛选 | 选项 |
|---|---|
| 阶段 | 所有阶段 / 待开始 / 草稿 / 线稿 / ... / 已完成 / 已取消 |
| 来源 | 所有来源 / 米画师 / 小红书 / 微博 / ... |
| DDL 状态 | 全部 / 已逾期 / 即将到期 / 正常 |
| 类别 | 所有类别 / 头像 / 立绘 / Q版 / ... |
| 关键词 | 文本搜索（匹配标题、客户名、备注），300ms 防抖 |

右侧有「显示已归档」开关，默认隐藏已归档订单。

### 4.2 表格列

每行显示：标题、客户、来源、阶段、金额、截稿日、剩余天数、收款状态。点击行进入订单详情。

### 4.3 分页

右下角切换每页显示条数：15 / 30 / 50 / 100。

### 4.4 批量操作

勾选多个订单后，顶部出现批量操作按钮组：

- **批量改阶段**：一次性推进/回退多个订单阶段
- **批量改来源**：统一修改来源标记
- **批量改收款**：统一修改收款状态
- **批量归档**：将选中的订单归档

### 4.5 Markdown 导出

点击「导出」按钮，生成 `全部订单.md` 文件（保存在 `exports/` 目录），包含所有订单的结构化文本，方便外部查阅或打印。

## 5. 看板视图

看板以阶段列为核心的可视化流转工具。

### 5.1 阶段列

每列代表一个制作阶段（默认：待开始 → 草稿 → 线稿 → 细化 → 完稿 → 已完成）。列头显示该阶段的订单数量和金额合计。

### 5.2 拖拽流转

- **拖拽卡片**到另一列 → 自动更新订单阶段
- **快捷按钮**：鼠标悬浮在卡片上时出现 ◀（回退）/ ▶（推进）/ ✓（完成）按钮，点击快速切换阶段
- 列可水平滚动，适应多阶段场景

### 5.3 筛选

看板顶部有内容筛选框，可按关键词过滤卡片。

## 6. 订单管理

订单是整个系统的核心实体。本章详细说明订单的创建、编辑、财务计算和生命周期。

### 6.1 三种表单模式

| 模式 | 入口 | 特点 |
|---|---|---|
| **居中模态** | 各页面「新建订单」按钮 | 680px 居中弹窗，快速创建 |
| **右侧抽屉** | 日历/甘特图/列表中点击订单 | 480px 右侧滑出，上下文编辑 |
| **完整页** | 订单详情 → 编辑 | 独立页面，字段最全，含财务实时预览 |

三种模式包含相同的字段集，只是展示密度不同。

### 6.2 创建订单

**必填字段**：

- **标题**：订单名称（如"小明 立绘"）
- **客户**：下拉选择已有客户，或新建
- **金额**：总金额（元）

**选填字段**：

- **来源**：约稿渠道（米画师/小红书/微博/QQ 群/直接委托等）
- **类别**：稿件类型（头像/立绘/Q版/表情包/其他）
- **阶段**：当前制作阶段（默认"待开始"）
- **排期开始日 / 截稿日**：日期选择器
- **工时（小时）**：用于时薪统计
- **备注**：自由文本，支持图片标记 `[img:文件名]`
- **折扣 (%)**：折扣百分比（如 90 = 九折），选客户时自动带出 VIP 默认折扣，可手改或清空
- **收款方式**：整单 / 分期（默认整单）

### 6.3 财务模式

订单支持两种财务模式：

**直接委托**：无平台手续费，金额 = 实际到账。

**平台来源**（如米画师）：
- 平台费率自动填充（在「设置 → 来源管理」配置）
- 计算链：**折扣后金额 = 总金额 × 折扣%** → **平台手续费 = 折扣后金额 × 费率%** → **实际到账 = 折扣后金额 - 手续费**
- 折扣为空时跳过折扣步骤

所有金额实时预览，编辑时可直观看到最终到账数额。

### 6.4 分期收款

订单创建或编辑时，将收款方式从「整单」切换为「分期」：

- 进入订单详情后，出现**收款时间线**区域
- 每笔到账记录包含：日期、金额、备注
- 点击「记一笔」添加收款记录
- 时间线上方汇总显示：应收净额 / 已到账 / 待收
- 所有分期金额收齐后，自动标记为「已结算」并触发归档
- 分期按到账日归属月份（影响收入看板的月度统计）

**注意**：免收与分期互斥，设为免收时不能开分期。

### 6.5 截稿倒计时

编辑订单时，截稿日期旁显示**剩余天数徽标**：

- 绿色：剩余 7 天以上
- 橙色：剩余 3-7 天
- 红色：已逾期或剩余不足 3 天

修改截稿日期后徽标实时更新。

### 6.6 订单模板

如果你经常接同类型的约稿，可以创建订单模板来加速建单：

1. 进入「小工具 → 模板管理」（或从新建订单弹窗中选择）
2. 创建模板：设置标题、金额、类别、来源、阶段流程等预设值
3. 新建订单时，下拉选择模板 → 字段自动预填 → 微调后保存

模板与订单表单字段保持同步：新增的自定义字段会出现在模板中。

### 6.7 阶段流程预设

每个订单可以关联一套阶段流程预设：

- 在「设置 → 阶段流程管理」中创建预设（拖拽排序 + 自动均分进度百分比）
- 创建订单时可选择使用某个预设
- 订单会保存当时的阶段快照，后续修改预设不影响已有订单

### 6.8 归档机制

订单归档分**自动归档**和**手动归档**：

**自动归档条件**（同时满足）：
- 阶段为「完成」或「已取消/退单」
- 收款状态为「已结算」或「免收」

满足条件后系统会弹出确认对话框（可配置确认模式：立即归档 / 按完成月归档 / 手动确认）。

**手动归档**：在排单列表中点击订单的归档按钮。

归档后订单从默认列表中隐藏（可切换"显示已归档"查看），系统记录归档时间和是否逾期快照。

### 6.9 工时记录

订单编辑页可填写工时（小时），用于收入看板的时薪统计计算。如不关心时薪，可在设置中关闭时薪统计功能，工时字段将隐藏。

### 6.10 编辑与保存

- 所有编辑模式下支持 **Ctrl+S** 快捷保存
- 抽屉和模态保存后自动刷新当前视图
- 编辑中离开页面弹出"未保存"确认

## 7. 收入看板

收入看板以图表方式展示你的财务数据，支持自定义布局。

### 7.1 图表概览

看板包含以下图表（可通过 gridstack 自由拖拽调整位置和大小）：

| 图表 | 说明 |
|---|---|
| **月度收入** | 柱状图，按月显示到账净额。分期收款按到账日归属月，整单按排期月归属 |
| **每月预计** | 虚线折线图，展示待收部分按排单月的预计收入 |
| **年收入累进** | 折线图，年度累计收入趋势 |
| **品类分布** | 饼图/环形图，按稿件类别分布（毛额/净额分列） |
| **客户排名** | 条形图，Top 8 客户消费金额排名 |

### 7.2 时薪统计

如果开启了时薪统计（设置 > 时薪统计），看板会额外显示：

- **本月/历史平均时薪**：实际到账 / 记录工时
- **近 12 月时薪趋势**：折线图
- **品类/来源时薪**：条形图对比不同类别和来源的时薪水平
- **报价建议**：基于历史时薪 x 预估工时 / (1-平台抽成率)，附 P25~P75 区间参考

### 7.3 年份与时间范围

- 年份自动发现（根据数据中存在的年份生成下拉选项）
- 时间范围切换：近 3 月 / 近 6 月 / 近 12 月

### 7.4 自定义布局（gridstack）

- 拖拽图表卡片改变位置
- 拖拽卡片右下角调整大小
- 布局自动保存到浏览器 localStorage，刷新后保持
- 点击「重置布局」恢复默认排列

## 8. 画廊

画廊以瀑布流方式展示你的作品图片。

### 8.1 浏览

- **瀑布流布局**：自动适应不同尺寸的图片，错落有致
- **无限滚动**：向下滚动自动加载更多
- **筛选**：按客户、类别、阶段筛选作品

### 8.2 图片上传

图片通过订单编辑上传（不是画廊本身上传）：

1. 进入订单编辑（抽屉或完整页）
2. 在「作品图片」区域点击上传或 **Ctrl+V 粘贴**剪贴板图片
3. 每张图自动生成三档：原图 / 预览图 / 缩略图
4. 单个文件限制 10MB

### 8.3 Lightbox 查看

点击画廊中的图片，弹出 Lightbox 全屏预览：

- 左右箭头切换上/下一张
- ESC 关闭
- 显示图片所属订单信息

## 9. 客户管理

管理你的约稿客户信息。

### 9.1 客户列表

- 按消费金额排序（默认）
- 每行显示：客户名称、消费总额、下单次数、标签
- 支持搜索过滤

### 9.2 新建/编辑客户

点击「新建客户」或在列表中点击客户进入编辑：

- **基本信息**：名称（必填）、联系方式、备注
- **VIP 标记**：勾选后该客户成为 VIP 客户
- **默认折扣 (%)**：VIP 客户可设置默认折扣值，新建订单时自动带入
- **标签**：自由标签（如"长期合作""海外客户"）

### 9.3 VIP 客户

VIP 客户在列表中以徽标标识。创建订单时选择 VIP 客户，折扣字段自动填入其默认折扣值（可手动修改或清空）。

### 9.4 客户详情页

## 12. 数据与备份

### 12.1 数据库位置

| 版本 | 默认位置 |
|---|---|
| 安装版 | 安装目录下的 `orders.db`（默认 `%LOCALAPPDATA%\oimimo\orders.db`） |
| 便携版 | 解压目录下的 `orders.db` |

数据库是单个 SQLite 文件，包含所有订单、客户、设置数据。

### 12.2 关联文件

除数据库外，以下目录也包含用户数据：

| 目录 | 内容 |
|---|---|
| `uploads/` | 订单作品图片（原图/预览/缩略图三级） |
| `backups/` | 应用内备份文件 |
| `exports/` | 导出的 Markdown 文件 |
| `logs/` | 运行日志 |

### 12.3 手动备份与恢复

**最简备份**：复制 `orders.db` + `uploads/` 文件夹到安全位置。

**完整备份**：复制整个程序目录。

**恢复**：将备份的 `orders.db` 覆盖到程序目录，`uploads/` 也覆盖回去。

### 12.4 迁移到新电脑

1. 在旧电脑上：复制整个程序目录（或至少 `orders.db` + `uploads/`）
2. 在新电脑上：安装/解压程序，将上述文件覆盖到新程序目录
3. 启动程序，所有数据完整恢复

### 12.5 数据导入导出

**导出**：
- 排单列表页提供「导出」按钮，生成 Markdown 格式的全部订单文件
- 价目表支持导出为 PNG 图片

**导入**：
- 支持浏览器插件导入（米画师订单、Firefox 剪藏），需要安装对应的浏览器扩展
- 导入时会校验来源信息，确保数据一致性

### 12.6 覆盖安装新版本

安装版升级时直接运行新版安装程序，选择相同安装路径即可。安装程序会覆盖程序文件但**不会删除** `orders.db` 和 `uploads/` 等用户数据。

## 13. 常见问题

### 13.1 Windows SmartScreen 提示

**现象**：首次运行弹出"Windows 已保护你的电脑 / 未知发布者"。

**原因**：个人开发者未购买代码签名证书（每年数百至上千元），不影响软件安全性。

**处理**：点击"更多信息" > "仍要运行"。

### 13.2 防火墙弹窗（日历订阅）

**现象**：启用日历订阅后，Windows 弹出网络权限询问。

**处理**：点击"允许"。之后不会再弹窗。如果误点了"取消/拒绝"，重新在设置页关闭再开启订阅，Windows 会重新弹窗。

**iPad/手机连不上**：确认手机和电脑在同一 WiFi/局域网，检查 Windows 防火墙是否有 oimimo 的入站规则。

### 13.3 数据丢失恢复

**有备份**：设置 > 数据备份 > 选择备份点恢复。

**无备份**：如果 `orders.db` 文件损坏但仍存在，可尝试用 SQLite 工具 `.recover` 命令恢复部分数据。建议平时养成定期备份的习惯。

### 13.4 端口冲突

**现象**：启动后无法访问 `http://127.0.0.1:1096`。

**原因**：1096 端口被其他程序占用。

**处理**：
1. 打开命令行执行 `netstat -ano | findstr ":1096"` 查看占用进程
2. 关闭占用程序，或修改本软件端口（暂不支持界面配置，需联系开发者）

### 13.5 程序无法启动

**处理步骤**：
1. 检查是否有其他 oimimo 进程在运行（任务管理器中查找），如有先结束
2. 检查 `logs/` 目录下最新的日志文件，查看错误信息
3. 尝试以管理员身份运行
4. 如仍无法启动，携带日志信息反馈

## 附录 A：业务口径速查

### 收款状态（5 值锁定）

| 状态 | 含义 |
|---|---|
| 已收定金 | 收到部分定金，尾款未结 |
| 未收款 | 尚未收到任何款项 |
| 已结算 | 全部款项已收齐 |
| 欠款 | 客户欠款未付 |
| 免收 | 免费委托，不收费 |

### 财务计算链

```
折扣后金额 = 总金额 x 折扣%        (折扣为空时跳过)
平台手续费 = 折扣后金额 x 费率%     (仅平台来源)
实际到账   = 折扣后金额 - 平台手续费
```

### 自动归档条件

同时满足以下条件时自动归档：
- 阶段 = 完成 或 已取消/退单
- 收款状态 = 已结算 或 免收

### 时薪公式

```
时薪 = 实际到账 / 记录工时 (加权口径)
```

### 月度收入归属

- 整单收款：按排期月归属
- 分期收款：按每笔到账日归属月份
