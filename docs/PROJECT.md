# oimimo scheduler — 项目说明书

> **版本**: V2 开发版 · **更新**: 2026-07-13
> **技术栈**: Python Flask 3 + SQLite (WAL) + HTMX 2 + Jinja2 + Pydantic v2 + Tkinter 启动器

面向**独立插画师**的本地接单排单管理工具，覆盖完整工作流：

```
接单 → 排期 → 跟进 → 收款 → 统计 → 归档
```

**核心原则**：本地优先（SQLite 单文件、零网络依赖）· 桌面集成（启动器+浏览器，类原生体验）· 动态可配置（注册表/主题/选择列表免改代码）· HTMX 无刷新 · 不 SaaS 化。

## 快速开始

| 方式 | 命令 | 端口 |
|---|---|---|
| 启动器（推荐） | `python launcher.py` | 5001（可传参覆盖） |
| 直接运行 | `python app.py`（debug 仅此处启用） | 5000（`--port` 覆盖） |
| 批处理 | `run.bat` | 5001 |

依赖：`pip install -r requirements.txt`（flask≥3.0 / pydantic≥2.0 / flask-cors / Pillow≥10.0 / pystray≥0.19）。启动器会自动补装缺失依赖。数据文件（orders.db / uploads / exports / logs）生成在数据目录，打包后与 exe 同级。

## 功能矩阵

### 主页仪表盘 `/`
- 统计卡 5 指标：进行中 / 本月收入(+环比) / 逾期 / 已完成 / 累计收入；点击弹**小票明细**
- 可折叠时间范围：预设（本月/季度/年/全部）+ 自定义日期，localStorage 记忆
- 甘特图（Frappe Gantt）：日/周/月/年 4 视图，拖拽改排期，仅进行中/全部切换
- 本周排单表（全量取数防截断）+ 逾期提醒表

### 收入看板 `/income`
- Chart.js 4 图表：月度收入（点小票）/ 每月预计(虚线) / 年收入累进 / 品类分布(毛净分列)
- 客户消费排名 Top 8（点击进详情）；年份自动发现切换；近 3/6/12 月范围

### 日历视图 `/calendar`
- FullCalendar 6 月/周视图；5 种着色模式（来源/阶段/DDL/收款/类别）独立调色
- 未排期池拖拽入历；事件拖拽移动/调时长自动保存；逾期红边发光；订单级颜色覆盖

### 排单列表 `/orders`
- 12 列分页表（15/30/50/100 条）；阶段/来源/DDL/搜索多维筛选（300ms 防抖）
- 批量操作按钮组（阶段/来源/收款/其他）；归档切换；Markdown 导出+打开文件夹

### 看板 `/orders/kanban`
- 7 阶段列拖拽（SortableJS）；hover 快捷 ◀/▶/✓；列头 sticky + 列统计；内容筛选；全量加载

### 画廊 `/gallery`
- 瀑布流 + 无限滚动懒加载；多条件筛选；Lightbox 查看；订单多图上传（粘贴/选择，≤10MB，自动生成预览+缩略图）

### 客户管理 `/customers`
- 列表按消费排序；标签 badge；total_spent/purchase_count 自动统计
- 详情页：基本信息 + 历史订单 + 作品画廊；批量删除（关联单客户自动跳过）

### 订单表单（3 种模式）
| 模式 | 入口 | 特点 |
|---|---|---|
| 居中模态 | 各处「新建」 | 快速创建，Notion 风 680px |
| 右侧抽屉 | 日历/甘特/列表点击 | 上下文编辑 480px，含日历颜色选色器 |
| 完整页 | 详情→编辑 | 平台/直接双财务模式实时预览 |

支持**订单模板**（存为模板/模板新建）与归档确认链（月份归属选择）。

### 设置 `/settings`（4 Tab）
- **主题**：18 色全局变量 + 日历着色 5 模式调色板（原生 ColorPicker）+ 自定义主题 CSS 导入/应用
- **订单属性**：来源管理（平台标记+费率%）· 收款状态（5 值锁定只读）· 稿件类别管理
- **外观**：字号 4 档 · 字体 3 种
- **系统**：重启指引 · 前端错误日志 · 缓存清理 · 快捷键

### 数据导入导出
- Markdown 全量导出（`exports/全部订单.md`）
- 浏览器插件导入（米画师，`POST /api/import/mihuashi`，来源校验）
- CSV/Excel 导出：规划中

## 关键业务口径（速查）

- **收款状态 5 值锁定**：已收定金 / 未收款 / 已结算 / 欠款 / 免收
- **自动归档**：阶段=完成或退单 + 收款∈{已结算,免收} → 归档并写 `completed_at`/`is_overdue` 快照；免收归档但不计收入
- **财务**：`income = 定金+尾款`；平台来源 `platform_fee = income × 快照费率%`；`actual_received = income − fee`
- **统计金额**：一律 `actual_received` 净额；收入按 `scheduled_end` 归月
- **复购**：查询时计算（同客户他单数，排除退单）

> 完整口径定义见 ARCHITECTURE.md §6.6 统计口径字典。
