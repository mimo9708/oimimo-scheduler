# oimimo scheduler — 项目说明书

> **版本**: V2 开发版 · **更新**: 2026-07-28
> **技术栈**: Python Flask 3 + SQLite (WAL) + HTMX 2 + Jinja2 + Pydantic v2 + Tkinter 启动器

面向**独立插画师**的本地接单排单管理工具，覆盖完整工作流：

```
接单 → 排期 → 跟进 → 收款 → 统计 → 归档
```

**核心原则**：本地优先（SQLite 单文件、零网络依赖）· 桌面集成（启动器+浏览器，类原生体验）· 动态可配置（注册表/主题/选择列表免改代码）· HTMX 无刷新 · 不 SaaS 化。

## 功能矩阵

### 主页仪表盘 `/`
- 统计卡 5 指标：进行中 / 本月到账(+环比，Spec 26 事件流口径：分期按到账日、整单按排期月) / 逾期 / 已完成 / 待收金额(= 应收净额 − 已到账)；点击弹**小票明细**（待收小票分期单按单列三数：应收/已到/待收；到账小票分期单按笔一行带「分期」标签）
- 可折叠时间范围：预设（本月/季度/年/全部）+ 自定义日期
- 甘特图（Frappe Gantt）：日/周/月/年 4 视图，拖拽改排期，今日居中定位
- 本周排单表 + 逾期提醒表

### 收入看板 `/income`
- Chart.js 图表：月度收入（按到账归属 · 净额）/ 每月预计(虚线，待收部分按排单月 · 净额) / 年累进 / 品类分布(毛净分列) / 客户排名 Top 8
- **时薪统计**：本月/历史平均时薪 + 近 12 月趋势折线 + 品类/来源条形图（全局开关控制，单订单可排除）
- **报价建议**：历史时薪 × 预估工时 ÷ (1−抽成)，附 P25~P75 区间
- **gridstack 自定义布局**：Notion 式拖拽+缩放+持久化
- 年份自动发现切换；近 3/6/12 月范围

### 日历视图 `/calendar`
- FullCalendar 6 月/周视图
- **5 种着色模式**（来源/阶段/DDL/收款/类别）独立调色 + 配色预设
- 未排期池拖拽入历；事件拖拽移动/调时长自动保存；逾期红边发光

### 排单列表 `/orders`
- 分页表（15/30/50/100 条）；阶段/来源/DDL/类别/搜索多维筛选（300ms 防抖）
- 批量操作按钮组（阶段/来源/收款/其他）；归档切换
- 每行显示剩余天数徽标（逾期红色/临期橙色/正常）

### 看板 `/orders/kanban`
- 阶段列拖拽（SortableJS）；hover 快捷 ◀/▶/✓
- 列头 sticky + 列统计（卡数+金额）；内容筛选；全量加载

### 画廊 `/gallery`
- 瀑布流 + 无限滚动懒加载；多条件筛选；Lightbox 查看
- 订单多图上传（粘贴/选择，≤10MB，自动生成预览+缩略图）

### 客户管理 `/customers`
- 列表按消费排序；标签 badge；total_spent/purchase_count 自动统计
- 详情页：基本信息 + 历史订单 + 作品画廊；平均时薪
- **VIP 客户**（Spec19）：VIP 徽标（列表行内 + 详情标题旁）+ 默认折扣 (%)；新建订单自动带出折扣快照

### 订单表单（3 种模式）

| 模式 | 入口 | 特点 |
|---|---|---|
| 居中模态 | 各处「新建」 | 快速创建 680px |
| 右侧抽屉 | 日历/甘特/列表点击 | 上下文编辑 480px + ColorPicker |
| 完整页 | 详情→编辑 | 平台/直接双财务模式实时预览 |

支持**订单模板**（`/templates` 完整页卡片式 CRUD 管理，新建订单弹窗可下拉预填/删除模板）与**阶段流程预设**（可拖拽排序+自动均分百分比）。截稿日期旁实时显示剩余天数。编辑态支持 Ctrl+S 快捷保存。五种表单（完整页/抽屉/模态新建/模态编辑/模板）均含**折扣 (%)** 输入：选客户自动带出其默认折扣（可手改/清空），实时预览「折后→费→实收」。

**分期收款**（Spec 26）：五种表单均含**收款方式**开关（默认「整单」，老习惯零差异；切「分期」显示提示）。分期单详情页提供**收款时间线**（按到账日排序：日期/金额/备注 + 应收净额/已到账/待收三数汇总 + 行内编辑器记一笔/改/删）；收齐自动结算置「已结算」并走归档链；只进不退（删笔不回退状态，不一致显示警告条）；免收与分期互斥。

### 设置 `/settings`

- **主题设置**：11 色全局变量调色 + 自定义 CSS 主题导入/应用 + **深色主题引擎（Spec 32）**：按背景亮度自动判深、自动派生对比字色/深色变量/原生控件配色，全页面双主题对比度审计保障
- **着色模式**：5 种着色维度独立调色板 + 配色预设（保存/选用/更新/删除）
- **来源管理**：平台标记 + 费率% 配置；费率自动填充到订单表单
- **VIP 折扣预设**（Spec19）：预设折扣值标签增删（默认 95/90/88/80），挂到客户表单折扣输入 datalist
- **收款状态**：5 值锁定只读
- **稿件类别管理**：增删 + 合并功能
- **阶段流程管理**：流程预设编辑器（拖拽排序+进度均分）
- **时薪统计**：全局开关 + 单订单排除
- **外观**：字号 4 档 · 字体 3 种
- **快捷键**：自定义按键绑定
- **数据备份**：手动备份/恢复/删除 + **备份位置可配置**
- **日历订阅**（Spec20）：局域网 ICS 订阅（0.0.0.0:1097 第二监听 + token 鉴权），手机日历（iOS/Android）同步排期与截稿日；开关/URL 复制/令牌旋转；默认关闭
- **系统**：错误日志 · 更新检查 · 意见反馈入口

### 小工具平台 `/tools`（Spec22）

侧边栏「小工具」入口 → 市场页（搜索 + 分组过滤 + 最近使用横条）→ 工具详情页；内置工具注册进 `TOOL_REGISTRY`，第三方接入约定见 `.qoder/docs/tools-dev-guide.md`（只做约定不做加载器）。

- **回复模板**：常用话术卡片式管理（分组侧栏 + 一键复制 + 关键词搜索高亮 + 分组重命名/删除）
- **价目表**：双视图——长条视图（默认落地，画师圈范式菜单排版：分类编号分节 + 例图横排 + 暖金价格大字 + 完整说明 + 附注页脚，整图导出 PNG 下载/复制到剪贴板）⇄ 卡片视图（分类卡片网格响应式 `auto-fill min(300px,100%)`，每张卡片单卡下载按钮）；视图切换分段控件 + localStorage 记忆；「按分类导出」恒从卡片模板源渲染 640px（产物 1280px@2x，与当前视图无关）；自研 foreignObject 导出器（`renderOffscreenToBlob`）离线可用。编辑模式（点「编辑」进入，分类内拖拽排序 + 例图管理）。价目项目支持分类/价格区间（起价–上限可空）/单位/说明/多例图（每项最多 10 张）
- **小票打印机**（Spec23 + Spec24）：双模式——预览模式（默认落地，复古小票渲染：制品明细/赠品划线/附加服务主子行/倍率折扣定金条件行/条码/锯齿边，打印白底黑字 + PNG 下载/复制）；编辑模式（六分区编辑器 + 实时预览：制品增删改/价目表 datalist 联动填价/倍率折扣定金/文案/四预设样式 list-retro-hand-mono/纸色墨色/自定义背景/主图三档灰度-抖动-彩色，彩色保原色）。样式可存为模板复用（只存样式文案不存制品）。**Spec24 计算模型**：单品倍率（商用×2/买断×3 快捷预设 + 可手改，预设文案/数值自定义）+ 单品/整单折扣双形态（直减金额 / 中文折数如 8.8 折），小票行内角标展示价格构成（×2 商用 / 9 折）

## 关键业务口径（速查）

- **收款状态 5 值锁定**：已收定金 / 未收款 / 已结算 / 欠款 / 免收
- **自动归档**：阶段=完成或退单 + 收款∈{已结算,免收} → 归档并写 `completed_at`/`is_overdue` 快照
- **财务**：`income = 定金+尾款`；**先折后费**（Spec19）：折扣非空 → `折后 = income × 折扣%`，平台来源 `platform_fee = 折后 × 快照费率%`；`actual_received = 折后 − fee`；折扣为订单级快照（客户改折扣不回溯存量订单）
- **统计金额**：工作口径一律 `actual_received` 净额；现金口径走收款事件流（Spec 26）——本期到账：整单按排期月 / 分期按到账日；待收金额 = 应收净额 − 已到账（分期）
- **复购**：查询时计算（同客户他单数，排除退单）
- **时薪**：`actual_received / work_hours`（加权口径）；全局开关 + 单订单排除

> 完整口径定义见 ARCHITECTURE.md §6.5 统计口径字典。
